# Проверка Discord bridge, 24.11.2026

Код подготовлен для выбранных серверов `1317165120128028773` и `1525821262054817842`. В рабочей SQLite поставлены два full-задания. Оба пока queued, клиент офлайн, сохранённых сообщений нет. Это не выполненная выгрузка.

## Подтверждено

- `node --test cloud/test/*.test.js`: после настройки Wispbyte 66 тестов, 65 успешно, 0 ошибок, 1 пропущен.
- Покрыты: очередь, запрет чужих guild IDs, пустой список, отдельная авторизация плагина, потеря подтверждения пакета, реальное закрытие/открытие базы и курсор, более 100 сообщений, архивные ветки, частичный доступ, версии правок, полная сверка удалений, обновление закрепа во время прохода, лимит места и 900-секундное расписание без прямого запроса Discord с хоста.
- Проверен фактический список инструментов локального MCP и его перенаправление в REST без сетевых сокетов, с ключом в заголовке.
- `node cloud/scripts/check.js`: синтаксис 37 файлов и 25 путей OpenAPI. TypeScript плагина проверен после штатного удаления типов Node.js; это не полноценная сборка Vencord.
- `node cloud/scripts/release.js`: выпуск по списку разрешённых исходных файлов, без `.env`, личных данных, базы, cookie и резервных копий.

## Ограничения среды

Один тест облачного SDK MCP пропущен, поскольку пакет `@modelcontextprotocol/server` не установлен. Попытка проверить npm registry завершилась ENOTFOUND для registry.npmjs.org.

В старом наборе `node tools/workspace.js test mcp` прошли 8 из 12 тестов; 4 теста с настоящим HTTP-соединением к локальной имитации сервиса не прошли. Отдельный минимальный HTTP-probe показал `fetch failed`, причина EACCES для 127.0.0.1. Сетевая проверка SDK, подключение живого клиента и эти HTTP-тесты требуют среды с разрешённой сетью. Ослабление защиты и обход запретов не выполнялись.

Найдена установленная готовая сборка Vencord, но исходный checkout не предоставлен. Полная сборка с userplugin, его установка в Discord и живое чтение выбранных серверов не проверены. Необходимо установить плагин по discord-vencord.md и настроить отдельный ключ Workspace и адрес назначения. Discord account token для этого не нужен.
