# Discord через личный клиент

Цель: по запросу MCP и каждые 900 секунд получать данные только явно выбранных Discord-серверов. Бота добавить нельзя. Источник — открытый клиент с собственным Vencord userplugin; токен Discord остаётся внутри клиента.

Выбранный подход: первая полная постраничная загрузка доступной текстовой истории, затем новые сообщения и наблюдаемые правки/удаления плюс сверка структуры и закрепов каждые 15 минут. Принудительный полный проход доступен отдельно. Постоянный повтор всей истории дорог и не нужен. Прямые пользовательские токены на хостинге остаются лишь старым совместимым режимом, новый транспорт называется `vencord`.

Облачный процесс хранит ограниченную SQLite-базу, задания, курсоры, сообщения и версии. Плагин последовательно получает страницы через уже авторизованный Discord и передаёт небольшие пакеты. MCP сразу возвращает ID задания; чтение состояния отдельно. Обрыв продолжает текущий курсор, повтор пакета идемпотентен. Каналы и сообщения никогда не считаются полностью выгруженными при ошибке или лимите места.

Два списка допуска: DISCORD_GUILD_IDS на сервере и выбранные guild IDs в плагине. Пустой список ничего не экспортирует. DISCORD_CHANNEL_IDS дополнительно ограничивает сообщения (включая ветки выбранного родителя); пустой список означает все доступные текстовые каналы выбранного сервера. Личные сообщения, скрытые каналы, аудио, видео и двоичные файлы не выгружаются. Сохраняются исходный текст, embeds, метаданные вложений, роли, права, ссылки, даты и наблюдаемые версии. Полный список участников не собирается.

Архивные и активные ветки перечисляются отдельными запросами. Недоступность перечисления отражается как частичная выгрузка. Полная загрузка позволяет сверить удаления; обновление новых сообщений не восстанавливает пропущенные старые правки. Режим full нужен для повторной полной сверки после длительного офлайна. Клиент должен работать; облако само не авторизуется в Discord. Vencord и автоматизация личного аккаунта нарушают условия Discord; отсутствие токена в облаке это не меняет.
